# Random_Limbus_Identity
림버스 컴퍼니 인격 랜덤 가챠 프로그램

## 실행

Unity에서 `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.
씬에는 `Assets/Prefabs/Roulette.prefab`의 인스턴스가 배치되어 있습니다.
다른 씬에서도 이 프리팹을 끌어다 놓으면 사용할 수 있습니다.
`Roulette` 오브젝트가 첨부한 N사 자판기 배경에 슬롯 UI와 입력 시스템을 실행 시 생성합니다.
스크린에서는 인격 이미지만 회전하며, 결과 이름은 추첨이 끝난 뒤 아래 검은 명판에 표시됩니다.
세 원형 버튼은 왼쪽부터 **인격 뽑기**, **전체 초기화**, **룰렛 종료**입니다.
배경의 빈 금속 판 위에 별도 버튼 스프라이트를 배치합니다. 기본 상태는 베이지색이며,
누르는 동안에는 회갈색의 눌림 이미지로 바뀝니다. 비활성 버튼도 눌린 모습으로 어둡게 표시됩니다.
종료는 빌드에서는 앱을 닫고, Unity Editor에서는 Play 모드를 끝냅니다. 회전 중에도 종료할 수 있습니다.
좌우 사각 패널은 남은 인격 수와 추첨 상태를 표시합니다.

현재 샘플 씬은 **이상 16개 인격 테스트 모드**입니다. `Assets/img/YiSang`의 이미지 16장이
인격 ID에 연결되어 있으며, 시작 화면에서도 첫 인격의 이미지를 확인할 수 있습니다.
전체 인격을 사용하려면 Play를 종료한 뒤 `Roulette`의 `Yi Sang Only`를 끄세요.
`Portraits`에는 인격 ID와 이미지 참조를 추가할 수 있습니다. 이미지가 없는 인격은 검은 화면으로
지나가며, 뽑힌 인격의 이름은 이미지 유무와 관계없이 하단 명판에 표시됩니다.

- **인격 뽑기**: 남은 인격 중 하나를 동일 확률로 먼저 확정하고, 한 칸짜리 슬롯이 위로 회전한 뒤 결과에서 멈춥니다.
- 기본 속도는 **남은 전체 후보를 1초에 한 바퀴**입니다. 1~2초간 빠르게 회전하고 4초간 감속하므로 총 5~6초 걸립니다.
- 회전 중에는 뽑기와 초기화를 잠급니다. 결과 공개 후 해당 인격만 제외합니다.
- **전체 초기화**: 현재 모드의 인격을 복원합니다(이상 테스트 16개, 전체 모드 189개). 모두 뽑으면 초기화 전까지 추첨이 비활성화됩니다.
- 회전이 오브젝트 비활성화 등으로 중단되면 해당 인격은 소모되지 않습니다.
- 현재 제외 상태는 실행 중에만 유지됩니다. 다른 수감자의 이미지 연결과 저장 기능은 추후 작업입니다.

`Roulette` 오브젝트의 `RouletteManager` Inspector에서 한 바퀴 시간, 최소 고속 회전 시간,
감속 시간을 조절할 수 있습니다. 정확한 결과에 정지하기 위해 고속 구간은 최대 한 바퀴만큼 늘어납니다.

한글은 Windows의 맑은 고딕 등 OS 글꼴을 사용합니다. 다른 배포 환경에서는 한글 글꼴을
프로젝트에 추가하고 `RoulletteUI` 컴포넌트의 Font에 지정할 수 있습니다.

## 검증

프로젝트 루트의 PowerShell에서 데이터와 회전 경로 검증:

```powershell
Add-Type -Path @('Assets/Scripts/IdentityData.cs', 'Assets/Scripts/IdentityDatabase.cs', 'Assets/Scripts/ReelSpinPlan.cs', 'Tests/RouletteChecks.cs')
[RouletteChecks]::Run()
```

후보 수 1~189의 모든 도착 지점을 30/60/144 FPS 및 지연 프레임 조건에서 확인합니다.
