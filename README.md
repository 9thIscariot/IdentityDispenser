# Random_Limbus_Identity
림버스 컴퍼니 인격 랜덤 가챠 프로그램

## 실행

Unity에서 `Assets/Scenes/Title.unity`를 열고 Play를 누릅니다.
빌드는 기본적으로 1920×1080 창 모드로 시작합니다. 설정 화면에서 전체 화면으로 변경할 수 있습니다.
골목 타이틀의 오른쪽 자판기를 누르면 `Roullet` 씬으로 이동합니다.
씬에는 `Assets/Prefabs/Roulette.prefab`의 인스턴스가 배치되어 있습니다.
다른 씬에서도 이 프리팹을 끌어다 놓으면 사용할 수 있습니다.
`Roulette` 오브젝트가 첨부한 N사 자판기 배경에 슬롯 UI와 입력 시스템을 실행 시 생성합니다.
스크린에서는 인격 이미지만 회전하며, 결과 이름은 추첨이 끝난 뒤 아래 검은 명판에 표시됩니다.
처음 실행하거나 전체 초기화하면 스크린은 꺼진 듯 검은색으로 표시되며, 뽑기를 누르면 이미지가 나타납니다.
세 원형 버튼은 왼쪽부터 **뽑기**, **정지**, **종료**입니다.
배경의 빈 금속 판 위에 별도 버튼 스프라이트를 배치합니다. 기본 상태는 베이지색이며,
누르는 동안에는 회갈색의 눌림 이미지로 바뀝니다. 비활성 버튼도 눌린 모습으로 어둡게 표시됩니다.
종료를 회전·감속 중이나 뽑기 완료 상태에서 누르면 후보 전체와 화면을 초기화합니다.
초기화된 대기 상태에서 다시 종료를 누르면 타이틀로 돌아갑니다.
왼쪽 사각 패널은 **설정** 버튼이고, 오른쪽은 **대기 / 뽑기 중 / 뽑기 완료**를 표시합니다.
좌우 패널 글자는 동일한 24 크기의 검은색 굵은 글꼴을 사용합니다.
설정 화면은 왼쪽 목록에서 **뽑기 설정**, **인격 설정**, **화면 설정**을 고르면 오른쪽에 해당 옵션을 표시합니다.
선택한 항목은 흰색, 선택하지 않은 항목은 빨간색입니다.
뽑기 설정에서 수감자 중복과 인격 중복을 각각 ON/OFF로 바꿀 수 있습니다.
기본값은 수감자 중복 ON, 인격 중복 OFF입니다. 수감자 중복 OFF는 이미 뽑은 수감자의 다른 인격도 후보에서 제외합니다.
중복 값을 바꾸면 이미 뽑은 결과를 기준으로 후보가 즉시 다시 계산됩니다.
인격 설정은 수감자 번호 순서의 3열×4행 목록입니다. 흰색으로 선택된 수감자의 인격만 뽑기 후보에 들어가며, 빨간색 항목은 후보에서 제외됩니다. 기본값은 12명 모두 선택입니다.

**12명 수감자의 이미지가 있는 인격 188개**를 추첨합니다. 모든 이미지가 고유 인격 ID에 연결되어 있습니다.
사용자 선택에 따라 이미지가 없는 돈키호테의 `오트쿠튀르:: 르누아르 브랜드 매니저` 1개는 제외합니다.
이 인격은 데이터에 남아 있으므로, 나중에 `Portraits`에 해당 ID(`don-quixote-010`)와 이미지를 추가하면 포함됩니다.
`Portraits Only`는 켜져 있고 `Yi Sang Only`는 꺼져 있습니다. 이상 한정 개발 테스트가 필요할 때만 `Yi Sang Only`를 켜세요.
화면은 1920×1080을 기준으로 배치하며, 가로 일러스트는 화면을 채우고 세로 카드는 전체가 보이도록 맞춥니다.

- **뽑기**: 남은 인격 중 하나를 동일 확률로 먼저 확정하고, 정지를 누를 때까지 스크린을 계속 회전시킵니다.
- 기본 속도는 **남은 전체 후보를 1초에 한 바퀴**입니다.
- **정지**: 현재 위치와 속도에서 즉시 감속을 시작하고, 확정된 인격에 정확히 멈춥니다.
  기본 감속 시간은 목표 위치에 따라 4초 이상 8초 미만입니다. 결과를 공개할 때만 후보에서 제외합니다.
- 회전 중에는 뽑기를 잠그고, 감속 중에는 정지도 잠급니다. 종료는 항상 누를 수 있습니다.
- **종료**: 회전·감속 중이거나 뽑기 완료 상태라면 이전 결과로 제외된 인격까지 전부 복원하고 화면을 비웁니다. 대기 상태에서 누르면 타이틀로 이동합니다.
- 회전이 오브젝트 비활성화 등으로 중단되면 해당 인격은 소모되지 않습니다.
- 현재 제외 상태는 실행 중에만 유지됩니다. 앱을 다시 실행하면 188개로 시작합니다.

`Roulette` 오브젝트의 `RouletteManager` Inspector에서 한 바퀴 시간과 최소 감속 시간을 조절합니다.
감속 거리가 목표 칸에 맞도록 감속 시간은 설정값에서 한 바퀴 시간의 4배 미만만큼 늘어날 수 있습니다.

한글은 Windows의 맑은 고딕 등 OS 글꼴을 사용합니다. 다른 배포 환경에서는 한글 글꼴을
프로젝트에 추가하고 `RoulletteUI` 컴포넌트의 Font에 지정할 수 있습니다.

## 검증

프로젝트 루트의 새 PowerShell 세션에서 수동 정지 경로와 상태 전이 검증:

```powershell
Add-Type -CompilerOptions '/nowarn:0649' -Path @('Assets/Scripts/IdentityData.cs', 'Assets/Scripts/IdentityDatabase.cs', 'Assets/Scripts/ReelSpinPlan.cs', 'Assets/Scripts/RouletteAnimatior.cs', 'Assets/Scripts/RouletteManager.cs', 'Tests/ManualSpinChecks.cs')
[ManualSpinChecks]::Run()
```

Unity 런타임 대역으로 실제 Manager/Animator 코드를 실행합니다. 1,863개 감속 경로와
정지 전 계속 회전, 중복 입력, 수감자 선택과 두 중복 설정의 후보 반영, 결과 1회 확정,
완료/회전/감속 중 종료 초기화, 타이틀 이동을 확인합니다.
이 검증은 실제 Unity 화면 렌더링과 버튼 클릭을 대신하지 않습니다.
